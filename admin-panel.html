Spec schema

Defines the structure of the Specifications tab on the vehicle editor — sections and fields. Adding a field here makes it available across every vehicle in that category.

Pricing components

Defines what makes up an on-road price. Each component has a formula type (flat / % of base / per-state rule) and rules can be overridden per state for components flagged as overridable.

Active formula
on_road_price = ex_showroom + (rto_charge × overridable) + (road_tax × overridable) + registration_fee + insurance_1y + (zero_dep × optional) + (tcs × conditional) + (hypothecation × loan_only) + smart_card_fee + fastag + (green_cess × overridable) + handling_charges
12 components · 4 mandatory · 3 overridable per state · 1 conditional (TCS triggers above ₹10L)
